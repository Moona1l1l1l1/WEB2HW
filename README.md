# ASP.NET Core Web API — Управление списком книг

**Дисциплина:** CSE5032 «Разработка веб-сервисов»  
**Модуль:** 02  
**Тема:** Реализация веб-сервиса с применением ASP.NET Core

## Цель работы

Целью работы является закрепление навыков создания Web API на ASP.NET Core, работы с контроллерами, маршрутизацией и HTTP-методами GET и POST.

## Описание проекта

В рамках работы разработан веб-сервис для управления списком книг.

Для хранения данных используется обычный список `List<Book>` без подключения базы данных.

Модель книги содержит следующие поля:

- `Id` — идентификатор книги;
- `Title` — название книги;
- `Author` — автор;
- `Year` — год издания.

## Реализованные API

### GET /api/Books

Возвращает список всех книг.

### POST /api/Books

Добавляет новую книгу в список.

Пример тела запроса:

```json
{
  "title": "Война и мир",
  "author": "Лев Толстой",
  "year": 1869
}
